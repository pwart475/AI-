# 魚機 AI × 人工決策台架構

這個 repository 保存「魚機決策台」的展示版 HTML，說明從企劃規格、AI 方向圖、人工決策、2D 母版、影片／後製／3D／特效 Reference，到正式製作工項的完整流程。

## 開啟方式

直接開啟根目錄的 `index.html`。

## 版本規則

- `index.html` 永遠更新為最新版。
- 歷史快照放在 `versions/`。
- 只保留最近三個版本。
- 新版本上傳後，超過三版的最舊快照才會刪除。
- 每版應保留日期與版本號，方便比較與回滾。

## 責任邊界

- AI：規格理解、候選生成、Reference、品質分析與修正建議。
- 人工：產品意圖、DNA 鎖定、審核、例外決策與正式驗收。
- 系統：版本、Gate、稽核、成本、工項輸出與回滾。
